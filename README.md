# Khashaba Dental Clinic

موقع عيادة د. محمد خشبة، مبني كتطبيق React أحادي الصفحة يدعم العربية والإنجليزية.

## البدء محليًا

```bash
npm ci
npm run dev
```

أوامر المشروع:

| الأمر | الاستخدام |
|---|---|
| `npm run dev` | تشغيل خادم التطوير على المنفذ 3000 |
| `npm run build` | إنشاء نسخة الإنتاج داخل `dist/` |
| `npm run preview` | معاينة نسخة الإنتاج |
| `npm run lint` | تشغيل ESLint |

لربط واجهة حجز المواعيد بخادم مختلف، أنشئ ملف `.env` محليًا واضبط `VITE_API_URL`. لا ترفع `.env` أو بيانات المرضى إلى Git.

## ملاحظات

- الصور والفيديوهات الثابتة موجودة تحت `public/`.
- إعداد إعادة كتابة المسارات إلى تطبيق SPA موجود في `vercel.json`.
- ملفات الوسائط العلاجية وبيانات الحالات حساسة؛ أبقِ المستودع خاصًا ولا تشاركها خارج الجهات المصرح لها.
